# Name Availability Source Map

Use current sources. Prefer official registries and first-party platform pages.

## Trademark

- USPTO Trademark Search: https://www.uspto.gov/trademarks/search
- WIPO Global Brand Database: https://branddb.wipo.int/
- EUIPO eSearch: https://euipo.europa.eu/eSearch/
- CNIPA / China trademark search: https://sbj.cnipa.gov.cn/

## Domains

- ICANN Lookup: https://lookup.icann.org/
- Registry or registrar availability pages for the relevant TLD.

## App Stores

- Apple App Store web search: https://www.apple.com/app-store/
- Google Play search: https://play.google.com/store/search

## Code and Packages

- GitHub search: https://github.com/search
- npm: https://www.npmjs.com/
- PyPI: https://pypi.org/
- crates.io: https://crates.io/
- RubyGems: https://rubygems.org/
- Packagist: https://packagist.org/
- Maven Central: https://central.sonatype.com/
- Go package discovery: https://pkg.go.dev/

## Social and Community

Check the channels relevant to launch:

- X/Twitter
- YouTube
- TikTok
- Instagram
- LinkedIn
- Reddit
- Product Hunt
- Discord public servers where relevant
- Jike
- Xiaohongshu
- WeChat official account search when relevant

## Search Patterns

Use combinations:

- exact quoted name
- name + product category
- name + app
- name + software
- name + trademark
- name + GitHub
- name + npm / PyPI / package
- name + target market language variants
