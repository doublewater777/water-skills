# 后缀与候选域名选择

来源：用户在本会话提供的 Web.Cafe / 哥飞经验整理，统计范围为2025.05–2026.08的14届新词新站月赛前20名（按UV），共278站、37种后缀；引语另含其他日期。以下作为用户的默认选域名偏好。数据未独立复核，百分比为约数；比赛样本的相关性不能证明后缀对SEO的因果影响，不推导排名保证或惩罚。

## 决策顺序

- 默认首选 `.com`；没有合适可注册候选，再按站点类型选 `.org`、`.net`、`.app`。`.ai`、`.io` 可作主流备选，结合预算与定位。
- 后缀影响有限，优先尽快上线和写好网页标题，不为争抢某个后缀长期搁置建站。
- 想要的主流后缀全部被注册时，默认换词或做关键词变体，优先于继续追同词的冷门后缀。
- 关键词域名尽量完全匹配；不可用时可加 `play`、`game` 或调整语序，以语义自然和站点相关为前提。
- 关键词站允许横杠；品牌名默认不推荐横杠。
- 默认避开 `.xyz`、`.top`、`.online`、`.site`、`.shop` 等用户认为垃圾站使用较多的廉价后缀；这是选域名偏好，不声称搜索引擎对这些后缀有统一惩罚。首年便宜也不能替代续费与总成本比较。
- `.ai` 按通常两年起注册做预算预检，并核实当前注册局/注册商的最短年限、首付总价和续费成本；不要把年单价当作实际扣款额。
- 用户已明确选定域名或后缀时保留其选择，说明差异即可；未经授权不要替换购买目标。这套规则不扩大购买或充值授权。

## 按站点类型选择

| 类型 | 默认推荐顺序 | 备注 |
|---|---|---|
| 游戏站 | `.com` → `.org` / `.app` | 有主流后缀时不优先 `.gg` |
| 游戏攻略 / 资讯 | `.com` / `.org` | `.wiki` 有成功案例，不作为默认退路 |
| 普通工具站 | `.com` → `.org` / `.net` / `.app` | 优先清晰语义与可上线性 |
| AI工具站 | `.com` / `.net` / `.org` → 预算允许再考虑 `.ai` | `.app`、`.io` 也可结合定位考虑 |
| 在线测试站 | `.com` → `.org` | 该分类仅14站，证据较少 |
| 内容 / 资讯站 | `.com` / `.net` / `.org` | 三者均可 |
| 品牌站 / SaaS | 先选合适且可注册的名称与后缀，盈利后考虑升级 `.com` | 不必为了精确品牌 `.com` 延误上线；例：Youmind.ai → Youmind.com |
| 国别 / 小语种站 | 可用 `.com` 或其他合适后缀，内容默认语言匹配受众 | 不必仅因语言选择国别后缀；各国别后缀的实名、居住或本地联系人要求逐一核实，不概括为全部必须实名 |

## 提供给用户的候选清单

有新站选名需求时先按上述规则生成少量相关候选，再做实时可注册查询。对可用候选列出：准确域名、后缀选择理由、注册商、最短年限、首付总额、续费、隐私和特殊注册条件。主流后缀均不可用时给出改词方案，不无限扩展冷门后缀。用户指定准确域名购买时无需重新展开选名。

## 样本背景（用户提供）

总体约占比：`.com`36%、`.org`20%、`.net`10%、`.app`8%、`.ai`和`.io`各约1%；用户汇总六种主流后缀占77%、其他31种占23%。分项均为约数，不据此反推精确站点数量。14个第一名：`.com`6、`.org`3、`.net`3、`.app`1、`.run`1；13个使用上述主流后缀。

冷门后缀高UV案例：`.one`236万/第2名/在线测试，`.life`21万/第2名/游戏工具，`.wiki`18.3万/第5名/游戏攻略，`.run`14.5万/第1名/AI视频工具，`.xyz`12万/第4名/在线测试。六种主流后缀的UV中位数约2.2万，其他31种约1.0万；这些是参赛样本表现，不代表只换后缀便会提升流量。

分类样本：游戏112站（com39%、org22%、app12%、net4%）；游戏攻略/资讯48站（com44%、org25%、net8%、wiki6%）；普通工具27站（com41%、org19%、net15%、app11%）；AI工具49站（com24%、net16%、org14%、ai6%）；在线测试14站（com36%、org21%）；内容/资讯28站（com25%、net25%、org14%）。

用户提供的哥飞引语要点：后缀影响微乎其微，不如写好标题（2025.09）；抢了com但没上站仍是零（2025.11）；主流后缀都被注册就改词（2025.09）；有主流后缀不买gg、横杠没关系（2026.09）；ai太贵，其余主流后缀也可（2025.03）；网站默认语言用日语即可，不必强求国别后缀（2023.08）。
