# Launch Distribution Platform Map

Use this to choose and shape channels. Generate only the platforms that fit the product and launch.

## App Stores

### App Store / Google Play

Best for: app tools, mobile apps, paid apps, subscriptions.

Generate:

- title/name direction
- subtitle or short description
- full description
- what's new
- keyword themes
- screenshot caption themes

Style:

- precise and benefit-led
- avoid unverifiable superlatives
- match privacy, subscription, and compliance claims to actual implementation

## China Platforms

### 微信公众号

Best for: narrative launch post, founder note, detailed product thinking.

Generate:

- title options
- opening hook
- structured article outline
- full post or section draft
- CTA

Style:

- story + concrete use case
- can explain product thinking
- avoid empty manifesto

### 头条号 / 今日头条

Best for: broad practical utility, topical framing, search/discovery.

Generate:

- title options
- short article
- practical benefit bullets
- CTA

Style:

- direct, useful, skimmable
- concrete problem and result

### 小红书

Best for: lifestyle/productivity tools, visual before-after, personal workflow.

Generate:

- title hooks
- note body
- bullet use cases
- hashtag set
- image/screenshot caption ideas

Style:

- first-person or scenario-led
- concrete daily workflow
- avoid hard-sell tone

### 即刻

Best for: indie app updates, builder notes, early-user community.

Generate:

- short post
- maker note
- concise ask for feedback

Style:

- conversational
- honest about what changed and why

### 知乎

Best for: problem explanation, comparison, workflow method, search-friendly evergreen content.

Generate:

- question angles
- answer outline
- answer draft
- soft CTA

Style:

- useful and explanatory
- avoid pure advertising

### 少数派

Best for: productivity apps, Apple ecosystem tools, workflow articles.

Generate:

- article pitch
- workflow narrative
- feature walkthrough
- screenshots needed

Style:

- polished, practical, workflow-focused

### V2EX

Best for: technical users, indie launches, developer/productivity tools.

Generate:

- post title
- concise body
- technical context
- feedback request

Style:

- humble, specific, non-marketing

### 朋友圈 / 微信群

Best for: close network distribution and early user ask.

Generate:

- short version
- personal version
- ask-for-feedback version

Style:

- human, direct, low polish

### 抖音 / Bilibili

Best for: visual demos, workflow transformations, app utilities with clear before-after.

Generate:

- 15-30 second script
- shot list
- caption
- CTA

Style:

- show the problem quickly
- demonstrate the payoff visually

## International Platforms

### Product Hunt

Generate:

- tagline
- description
- maker comment
- first comment / FAQ
- launch day reply themes

Style:

- clear category and benefit
- concise, upbeat, proof-backed

### Hacker News

Best for: technical novelty, founder story, open-source, developer tools.

Style:

- non-promotional
- problem and implementation details first
- avoid launch hype

### Reddit

Best for: community-specific problem solving.

Style:

- subreddit-native
- disclose affiliation
- ask for feedback
- avoid generic cross-posting

### X / Threads

Generate:

- short post
- long post
- thread

Style:

- concise and sharp
- one idea per post

### LinkedIn

Best for: professional workflow, founder narrative, B2B utility.

Style:

- business impact
- story and lesson
- less casual than X

### Email / Newsletter

Generate:

- subject lines
- preview text
- launch email
- update email

Style:

- clear why now
- one primary CTA

## Developer Channels

### GitHub Release / README

Best for: developer tools, open-source, integrations.

Generate:

- release notes
- README feature section
- migration notes

Style:

- factual
- setup and change details

### Dev.to / 掘金 / CSDN

Best for: technical implementation stories and developer education.

Style:

- teach something
- include code, architecture, or tradeoffs
