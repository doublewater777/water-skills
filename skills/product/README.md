# Product

Product discovery, validation, PMF, growth, and builder workflows.

- [builder-business-model](./builder-business-model/SKILL.md) - Validate who pays, why they pay now, and whether payment strengthens retention.
- [builder-fake-door](./builder-fake-door/SKILL.md) - Validate demand before building through waitlists, demos, manual service offers, and preorder tests.
- [builder-feature-cycle](./builder-feature-cycle/SKILL.md) - Record every feature increment as a learning cycle.
- [builder-framework](./builder-framework/SKILL.md) - Orchestrate Builder Framework stages, Gate checks, loop-backs, and project records.
- [builder-growth-channel](./builder-growth-channel/SKILL.md) - Choose product-matched growth channels and validate repeatable acquisition.
- [builder-hypothesis](./builder-hypothesis/SKILL.md) - Convert a raw idea into a falsifiable product hypothesis.
- [builder-manual-onboarding](./builder-manual-onboarding/SKILL.md) - Manually onboard the first 10-100 users to learn from direct user contact.
- [builder-mvp-loop](./builder-mvp-loop/SKILL.md) - Design a single closed-loop MVP that proves one core value chain.
- [builder-narrow-wedge](./builder-narrow-wedge/SKILL.md) - Find the smallest reachable user wedge with strong, frequent pain.
- [builder-pmf-maintenance](./builder-pmf-maintenance/SKILL.md) - Run recurring PMF health checks.
- [builder-retention-signals](./builder-retention-signals/SKILL.md) - Evaluate PMF through behavior, business, and emotional signals.
- [builder-scale-playbook](./builder-scale-playbook/SKILL.md) - Turn manually validated actions into repeatable systems and automation.
- [builder-super-users](./builder-super-users/SKILL.md) - Identify strongest users and reverse-engineer positioning.
- [builder-user-interviews](./builder-user-interviews/SKILL.md) - Run and analyze past-behavior user interviews.
